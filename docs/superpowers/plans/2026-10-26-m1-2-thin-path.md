# M1.2 Thin path: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `pawsman DIR` opens a collection directory, lists its requests, and sends the selected one over HTTP on a private tokio thread, showing status, time, size and the raw body in three panes; Esc cancels, Ctrl-Q joins every thread.

**Architecture:** `pawsman-model` parses `pawsman.toml` and `*.req.toml` text (pure, no I/O). `pawsman-core` reads the files (store), owns the engine thread with a pure `AppState::apply` reducer that returns effects, and publishes `Arc<Snapshot>`s through a callback. `pawsman-net` owns a tokio runtime on its own thread behind a sync handle: one connection per request (DNS, TCP, optional rustls, hyper HTTP/1.1), bodies capped in memory and spilled to a temp file. `pawsman-tui` turns snapshots into `Msg`s and draws a sidebar, a request pane and a response pane. `pawsman-test-support` gets a fake HTTP server, used by tests and by a `pawsman-fake` binary for manual runs.

**Tech stack:** tokio 1.54.1, hyper 1.12.0, hyper-util 0.1.21, http 1.5.0, http-body-util 0.1.5, bytes 1.12.1, rustls 0.23.46 (`ring`), tokio-rustls 0.26.6, rustls-platform-verifier 0.7.1, tokio-util 0.7.20 (cancellation), tempfile 3.27.0; everything from 1.1.

**Spec:** [M1 design, piece 1.2](../specs/2026-10-26-m1-http-client-design.md#12-thin-path).

## Global constraints

- Everything in the [1.1 plan's constraints](2026-10-26-m1-1-binary-terminal-splash.md#global-constraints) still holds.
- tokio, hyper, rustls appear only in `pawsman-net` and `pawsman-test-support`; no tokio type or `async fn` in any public signature of `pawsman-net` ([CODE-ARCHITECTURE §3](../../CODE-ARCHITECTURE.md#3-async)).
- `pawsman-model` does no I/O.
- Defaults: total timeout 30 s, connect timeout 10 s, body cap 16 MiB (settings `[http] timeout_ms`, `connect_timeout_ms`, `body_cap_bytes`).
- Every request logs `method`, `host`, `path`, `status`, `ms` (OBSERVABILITY P7), never the query string, headers or body.
- No idle redraws: the loop ticks (100 ms) only while a request is in flight.
- Unknown keys in collection and request files are an error, shown as an error node; the app keeps running.

## Review focus

1. **A server that never answers or trickles bytes forever**: the total timeout ends it with `net::timeout`, and Esc cancels it at any point (Task 5 `a_stalled_body_times_out`, `cancel_mid_body`).
2. **A huge response** (larger than the cap): memory stays at the cap, the rest goes to a temp file, the pane says how big it is (Task 5 `body_above_the_cap_spills_to_a_file`).
3. **Ctrl-Q while a request is in flight**: the process exits within a second, no thread left (Task 9 PTY `ctrl_q_during_a_request_exits`).
4. **A collection with a broken file next to good ones**: the good ones still send, the broken one shows its error (Task 2 `a_broken_file_becomes_an_error_entry`, Task 8 snapshot).
5. **Binary or non-UTF-8 response bodies**: shown as lossy text with a size, never a panic or a mangled terminal (control bytes replaced) (Task 8 `control_bytes_in_a_body_are_not_written_raw`).

### Task 1: model — collection and request files

**Files:** create `crates/pawsman-model/{Cargo.toml,src/lib.rs,src/error.rs,src/codes.rs,src/collection.rs,src/request.rs}`, `docs/errors/model/{not_a_collection,invalid_file}.md`.

**Interfaces — produces:**

- `RequestId` (newtype over `u32`, `Copy + Ord + Display`), `RequestId::new(u32)`.
- `Request` with `name() -> &str`, `method() -> &str`, `url() -> &str`, `headers() -> &[(String, String)]` (file order kept), `body() -> Option<&str>`, `has_template() -> bool` (any `{{` in url, headers, body); `Request::parse(text: &str, path: &Path) -> Result<Request, ModelError>`.
- `Collection` with `name() -> &str`, `entries() -> &[Entry]`, `request(RequestId) -> Option<&Request>`; `Entry` with `id() -> RequestId`, `path() -> &Path`, `kind() -> &EntryKind`; `EntryKind::{Request(Request), Invalid(ModelError)}`.
- `Collection::from_files(root: &Path, manifest: Option<&str>, files: Vec<(PathBuf, String)>) -> Result<Collection, ModelError>`: `manifest` is `pawsman.toml`'s text (`None` → `model::not_a_collection`); entries sorted by file name, ids assigned in that order from 1.
- `ModelError` (`ErrorInfo`, `Clone`), `codes::{NOT_A_COLLECTION, INVALID_FILE, ALL}`.

File format for this piece (1.3 widens it):

```toml
# pawsman.toml
format = 1
name = "Demo"
```

```toml
# users.req.toml
name = "List users"
method = "GET"
url = "http://127.0.0.1:8787/users"

[headers]
Accept = "application/json"

[body]
text = "..."
```

`kind` is optional and only `"http"` is accepted; `method` defaults to `GET`; `[headers]` keeps file order (parse into `toml::Table` with the `preserve_order` feature, or deserialize into `Vec<(String, String)>` through a `BTreeMap`-free visitor — use `toml::Table` and keep `toml`'s `preserve_order` feature on).

### Task 5: net — the runtime thread and sending

**Files:** create `src/runtime.rs` (`Net`, command loop), `src/send.rs` (one request), `src/body.rs` (cap and spill), `src/response.rs`; integration tests in `crates/pawsman-net/tests/it/{main,send}.rs` against `FakeHttp`.

**Interfaces — produces:**

- `NetConfig::new()` with `timeout(Duration)`, `connect_timeout(Duration)`, `body_cap(u64)`; defaults 30 s, 10 s, 16 MiB.
- `Net::start(config: NetConfig, sink: impl Fn(NetEvent) + Send + 'static) -> Result<Net, NetError>` (spawns thread `pawsman-net` with a multi-thread runtime, 2 workers); `Net::send(&self, id: RequestId, outgoing: Outgoing)`; `Net::cancel(&self, id: RequestId)`; `Net::shutdown(self)` cancels everything and joins; `Drop` does the same.
- `RequestId` here is `pawsman_model::RequestId` (net depends on model, per ARCHITECTURE).
- `NetEvent::{Done { id, response: Response }, Failed { id, error: NetError }, Cancelled { id }}`.
- `Response`: `status() -> u16`, `reason() -> &str`, `headers() -> &[(String, String)]`, `body() -> &Body`, `elapsed() -> Duration` (send to last byte), `ttfb() -> Duration`; `Body::{Memory(Bytes), Spilled { file: Arc<tempfile::TempPath>, len: u64, head: Bytes }}` with `len() -> u64` and `preview() -> &[u8]` (the in-memory part).

Behaviour: resolve with `tokio::net::lookup_host` (`net::dns`), connect with `TcpStream::connect` under the connect timeout (`net::connect`, `net::timeout(Connect)`), wrap in `tokio_rustls` for `https` with `rustls-platform-verifier` and ALPN `http/1.1` (`net::tls`), `hyper::client::conn::http1::handshake`, spawn the connection task, set `Host` (and `Content-Length` for a body), stream frames into `body::Collector` (memory up to the cap, then everything after the first cap bytes appended to a temp file; `net::spill` on write failure), all under the total timeout (`net::timeout(Total)`); a `CancellationToken` per request kept in a `BTreeMap<RequestId, CancellationToken>`; a cancelled request emits `Cancelled` only. Each finished request logs `info!(method, host, path, status, ms, "request")`.

**Files:** create `crates/pawsman-core/src/state.rs`; modify `settings.rs` (`[http]`).

**Interfaces — produces:**

- `Snapshot`: `collection() -> Option<&Collection>`, `load_error() -> Option<&ModelError>`, `status(RequestId) -> &RequestStatus`, `generation() -> u64` (bumps on every change).
- `RequestStatus::{Idle, Sending { since: Instant }, Done(Arc<Response>), Failed(NetError), Cancelled}`.
