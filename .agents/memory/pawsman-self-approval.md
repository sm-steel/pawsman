# Pawsman project self-approval policy

The user explicitly delegated project-level review and approval of tests-first gates, snapshots, visual checks and genuine quality-tool false positives to the agent. They also authorized merging the agent's own Pawsman PRs once checks pass and deciding minor review findings without another approval stop.

Record every self-approval and its reasoning in a ledger, commit body or PR. For a genuine false positive use the narrowest justified allowance, with its reason. Never loosen a rule to hide a true finding, weaken an approved test or bypass Git hooks. Follow the current repository rules and any newer direct instructions that override this recorded exception.

This authorization is scoped to Pawsman only. It does not apply to Citadel or other projects. See [tracking autonomy](pawsman-github-tracking-autonomy.md) and [product scope](pawsman-project-scope.md).
